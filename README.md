# Sidewalk AI Scoring Tool

This project is a simple Streamlit application for scoring sidewalk segments based on ADA compliance, risk, and priority.

## Files
- `app.py` : Streamlit user interface
- `scoring_engine.py` : core scoring logic
- `requirements.txt` : required Python packages

## How to run locally
Install packages:

pip install -r requirements.txt

Run the app:

streamlit run app.py
